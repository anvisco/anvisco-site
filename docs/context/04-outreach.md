# Outreach

## Principles

- 30 to 50 emails is a real opportunity range.
- Personalization beats volume.
- One specific issue beats generic critique.
- Use Loom when it helps the message land faster.
- Frame the issue as flow, trust, booking, or visibility.
- Do not insult the site.

## Opening line

- `I build websites that run, grow, and optimize your business.`

## Public reference

- Reference site: `https://anvisco.com`

## Offer path

- Lead wants a quick look: send the free snapshot.
- Lead wants to buy: send them to `/checkout`.
- Paid client: send them to `/portal`.

## Copy rules

- Use Anvis, not Anvisco, in prospect-facing copy.
- Do not default to Calendly as the main CTA if the current flow is audit first, checkout second.
- Do not use manual payment links.
- Do not mention backend tools to prospects.
